# Store Release Metadata — Draft

## App name

StickMe

## Subtitle / short description

Create fast. Save beautifully. Send instantly.

## Full description

StickMe turns real-life moments into personal stickers. Create a sticker from a photo, save it into My World™, and share it instantly with the people who matter.

Built for families, pets, junior sports, vehicles, small businesses, and everyday moments worth keeping close.

## Core features

- Create stickers from photos, camera, or files.
- Save stickers into My World™ categories.
- Share stickers through supported apps.
- Use a sticker-focused keyboard/IME flow.
- Local-first privacy posture.

## Keywords

stickers, keyboard, family, photos, pets, sports, memories, sticker maker, personal stickers

## Review notes

StickMe's custom keyboard/IME is sticker-focused. It does not collect keystrokes or transmit typed content. The main app creates and saves stickers locally; the keyboard only displays saved sticker thumbnails and selected sticker assets.
