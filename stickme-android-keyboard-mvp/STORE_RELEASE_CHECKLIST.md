# StickMe Store Release Checklist

## Product Gates

- [ ] User can select a photo.
- [ ] App saves photo as a local PNG sticker.
- [ ] App generates a local 160px thumbnail.
- [ ] Sticker appears in the parent app.
- [ ] Sticker appears inside StickMe keyboard.
- [ ] Sticker tap attempts rich image insertion.
- [ ] Fallback text appears when target app blocks insertion.
- [ ] Loop works offline.

## Android Gates

- [ ] Gradle sync succeeds.
- [ ] Debug build succeeds.
- [ ] Release build succeeds.
- [ ] Physical device install succeeds.
- [ ] Keyboard enablement succeeds.
- [ ] Messages test passes.
- [ ] WhatsApp test passes.
- [ ] Telegram test passes.
- [ ] Signal test passes.

## Store Gates

- [ ] Privacy policy URL live.
- [ ] Terms URL live.
- [ ] Support URL live.
- [ ] Data Safety answers match actual behavior.
- [ ] Store screenshots use approved/consented imagery.
- [ ] No public child/family image is used without written consent.
- [ ] App description does not exaggerate revenue or outcomes.
- [ ] Internal testing track has testers assigned.
- [ ] Release notes are plain and accurate.

## Monetization Gates

- [ ] Founding 100 offer written.
- [ ] Junior Team Pack offer written.
- [ ] Payment collection page ready outside app.
- [ ] First 10 families/teams invited.
- [ ] Feedback loop installed before subscription build.
